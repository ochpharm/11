약국-배송원 실시간 서버 연동 설정

📌 다른 폰/PC와 실시간으로 연동하는 방법

1. Google Firebase 콘솔(console.firebase.google.com)에서 무료 프로젝트를 만들고 Firestore Database와 익명 로그인을 켭니다.

2. 프로젝트 설정에서 발급된 firebaseConfig 중괄호({ ... }) 내용을 아래에 붙여넣고 저장하세요.

3. 약국과 배송원 기기 모두 같은 설정값을 저장하거나, Netlify Drop 등에 이 파일을 올려 인터넷 주소(URL)를 공유하면 즉시 실시간 연동됩니다.
